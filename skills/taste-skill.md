# Skill: Taste-Skill (High-Agency Frontend)

## Overview
This skill elevates the quality of design and frontend development, moving away from generic AI patterns ("slop") towards premium, modern interfaces.

## Baseline Configuration
- **DESIGN_VARIANCE**: 8 (Modern, asymmetrical, bold layouts)
- **MOTION_INTENSITY**: 6 (Fluid, purposeful animations)
- **VISUAL_DENSITY**: 4 (Spacious, high-end feel)

## Core Guidelines
- **No Emojis**: Do not use emojis in UI unless explicitly requested.
- **Iconography**: Use `@phosphor-icons/react` for a consistent, premium look.
- **Micro-physics**: Implement magnetic hover effects and elastic transitions.
- **Liquid Glass**: Use advanced glassmorphism with subtle borders and backdrop-blur.

## Technical Standards
- **Performance**: Use hardware-accelerated properties only (transform, opacity).
- **Isolation**: Keep heavy animations in lightweight client components.
- **Components**: Use modern rounded corners (min 16px - 32px for large cards).
- **Typography**: Prefer modern, curated fonts (Outfit, Inter, Playfair Display) with proper hierarchy and spacing.

## Anti-Patterns (Avoid)
- Generic Tailwind blue/gray combinations.
- Box shadows that look dirty (use soft, multi-layered shadows).
- Standard browser buttons or inputs.
