# Skill: Full-Output Enforcement

## Core Commandment
You must ALWAYS provide the full, complete code in every output. Placeholders like `// ... rest of code`, `// existing logic`, or `// TODO` are strictly FORBIDDEN.

## Operational Process
1. **Full Implementation**: Every file change must represent the entire target file or a complete, working component.
2. **Breadcrumbs**: Do not skip lines. If the file is large, prefer multiple targeted tool calls or a single large output if the context window allows.
3. **Continuation**: If an output is cut off by length limits, stop at a clean point and wait for the "continue" command to resume from the exact character where you left off.
4. **Consistency**: Ensure all imports and exports are preserved when modifying existing files.
